# Cinevia

Cinevia is a React + Vite streaming-style web app with:

- email sign-in/sign-up
- Google OAuth support through Supabase
- synced favorites
- synced continue watching
- profile display names
- movie and TV show detail pages

## Local development

1. Copy [`.env.example`](/d:/Cinevia/cinevia/.env.example) to `.env`.
2. Add your Supabase values.
3. Install dependencies with `npm install`.
4. Start the app with `npm run dev`.
